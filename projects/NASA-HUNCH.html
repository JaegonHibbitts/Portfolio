NASA HUNCH GUI

Software Project · Python · PyQt5

Description

Designed and implemented a Python-based graphical user interface (GUI) for NASA’s High School Students United with NASA to Create Hardware (HUNCH) program, facilitating streamlined project management and communication for student teams. The application was developed using the PyQt5 framework, providing an intuitive interface for users to access resources, submit project updates, and communicate with mentors. Key features include a centralized dashboard for tracking project milestones, integrated messaging functionality for direct communication between students and mentors, and a resource library containing relevant documentation and guidelines. The GUI was designed with scalability in mind, allowing for future feature additions such as automated notifications, progress analytics, and collaborative tools to further enhance the user experience and support the goals of the HUNCH program.
