NASA HUNCH GUI

User Interface Project · Python / PyQt

Description

For the NASA HUNCH program, I worked with a student team to develop a graphical user interface concept for an International Space Station application. I contributed to interface layout, usability decisions, and Python/PyQt development.

The project focused on communicating technical system information clearly through an accessible interface, and our team placed fourth in the NASA HUNCH competition.
